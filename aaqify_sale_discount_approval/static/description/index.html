Aaqify Sale Discount Approval

Control and authorize sales discounts with multi-rule threshold limits, automatic activity generation, and seamless UI auto-refresh.

Community & Enterprise

Module Interface & Workflow

Real-time approval activities created automatically when discount limits are exceeded.

Key Features

Automate discount management and maintain margin control effortlessly

Custom Approval Thresholds

Configure discount percentage limits per company and assign designated approving managers easily.

Automated Activity Feed

Generates approval activities instantly for authorized managers without blocking or failing database transactions.

Seamless Auto-Refresh

Uses client-side notification reloads—no hard red modal error popups or tedious browser refreshes required.

Auto-Completion on Confirm

When an authorized approver confirms the quotation, pending approval activities automatically mark as Done.

Smart Activity Cleanup

If a salesperson lowers the discount back within limits, the pending approval request is automatically removed.

Multi-Company Support

Fully multi-company compliant, isolating rule triggers according to selected order companies.

How It Works

1
Configure Rules

Set maximum discount % threshold and assign approver users in Sales > Configuration > Sale dist. Approval.

2
Create Quotation

Salesperson adds discount to order line. If it exceeds rule threshold, clicking 'Confirm' alerts user and logs approval task.

3
Manager Approval

Authorized manager reviews and confirms order. Activity updates to Completed state automatically.
